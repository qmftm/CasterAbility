# 설정

`plugins/CasterAbility/config.yml` 항목입니다. 바꾼 뒤에는 `/ca reload` 또는
`/ca config` GUI를 쓰세요.

## classic — 기본 능력 자동 설치

| 항목 | 기본값 | 설명 |
|---|---|---|
| `install` | `true` | 처음 켤 때 `plugins/Skript/scripts/CasterAbility/classic/` 에 능력 `.sk` 파일을 깔아둡니다. `classic` 폴더가 이미 있으면 건드리지 않습니다. 처음 상태로 되돌리려면 그 폴더째 지우고 재시작하세요 |

## game — 게임 진행

| 항목 | 기본값 | 설명 |
|---|---|---|
| `basic_health` | 20 | 기본 체력 |
| `basic_level` | 50 | 기본 경험치 레벨 |
| `auto_skip_second` | 80 | 자동으로 다음 단계로 넘어가기까지의 시간(초) |
| `ability_change_count` | 3 | 능력 재추첨 가능 횟수 |
| `infinity_hunger` | `true` | 배고픔 무한 |
| `infinity_duration` | `true` | 포션 효과 지속시간 무한 |
| `cooldown_bow` | `false` | 활에 쿨타임 적용 |
| `cooldown_shield` | `false` | 방패에 쿨타임 적용 |
| `weather_clear` | `false` | 게임 중 날씨를 맑음으로 고정 |
| `wreck` | 0 | 능력 사용 후 자동으로 거는 쿨타임을 이 비율(%)만큼 줄입니다. 0~100 |

## spawn — 게임 월드

| 항목 | 기본값 | 설명 |
|---|---|---|
| `world_name` | `casterability` | 이 이름의 월드 폴더(서버 루트)가 있으면 템플릿으로 보고, 게임마다 `<world_name>-game` 으로 통째로 복제해서 씁니다. 원본은 건드리지 않습니다. 없으면 게임마다 새로 생성합니다. 게임 월드는 게임이 끝날 때마다 통째로 지워집니다 |
| `random_spawn` | `true` | 스폰 위치를 무작위로 정합니다 |
| `random_radius` | 100 | 무작위 스폰 반경 |

## death — 사망 처리

| 항목 | 기본값 | 설명 |
|---|---|---|
| `drop_items` | `true` | 죽으면 아이템을 드롭합니다 |
| `drop_exp` | `false` | 죽으면 경험치를 드롭합니다 |
| `kick` | `false` | 죽으면 서버에서 추방합니다 |

## invincibility — 무적 시간

게임 시작 직후, 참가자와 능력을 추첨하는 동안 부여되는 무적 시간입니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `enable` | `true` | 무적 시간 사용 여부 |
| `second` | 90 | 무적 시간 길이(초) |
| `show_bossbar` | `true` | 보스바로 남은 시간 표시 |
| `invisible` | `true` | 무적 시간 동안 투명화 |

## worldborder — 월드보더

| 항목 | 기본값 | 설명 |
|---|---|---|
| `enable` | `true` | 월드보더 사용 여부 |
| `max_radius` | 500 | 시작 반경 |
| `min_radius` | 5 | 최종 반경 |
| `shrink_second` | 60 | 한 번 줄어드는 데 걸리는 시간(초) |
| `shrink_count` | 5 | 줄어드는 단계 수 |
| `shrink_random_center` | `true` | 줄어들 때마다 중심을 무작위로 다시 잡습니다 |
| `show_bossbar` | `true` | 보스바로 월드보더 상태 표시 |
