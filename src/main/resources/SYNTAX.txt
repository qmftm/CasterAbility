CasterAbility — 능력 작성 문법
================================

기본 능력(classic)
------------------
플러그인을 처음 켜면 기본 능력이 여기에 깔립니다.

    plugins/Skript/scripts/CasterAbility/classic/<능력>.sk

Skript가 자기 scripts 폴더 아래를 전부 읽기 때문에 그대로 동작합니다.
처음 설치한 직후에는 /sk reload all 을 한 번 하거나 서버를 재시작하세요.

설치 위치는 항상 위 경로입니다. 다른 곳으로 대신 설치하지 않습니다.

- classic 폴더가 이미 있으면 플러그인이 손대지 않습니다.
  능력 파일 하나를 지워도 재시작할 때 되살아나지 않습니다.
- 기본 능력을 처음 상태로 되돌리려면 classic 폴더째 지우고 재시작하세요.
- 자동 설치가 싫으면 config.yml 에서 classic.install 을 false 로 바꾸세요.

내 능력을 추가하려면 plugins/Skript/scripts/ 아래 아무 데나
.sk 파일을 만들고 아래 문법대로 쓰면 됩니다.

능력을 지우거나 이름을 바꾼 뒤에는 /ca reload 를 먼저 하고
/sk reload all 을 하세요. 순서가 반대면 지운 능력이 목록에 남습니다.


능력 정의 문법
--------------
능력은 on load 블록 안에서 정의합니다.

    on load:
        ability class "yandere":
            name: "얀데레"
            tier: 2
            description:
                "&d[&7패시브 &f- &d처음 본 순간]"
                "&f처음 공격한 플레이어를 &c집착 대상&f으로 지정합니다."

        ability "yandere_jealousy":
            class: "yandere"
            name: "질투"
            trigger: right_click
            item: iron ingot
            cooldown: 45

ability class 항목
    name         표시 이름. 없으면 id를 그대로 씁니다.
    tier         0=Legendary 1=S 2=A 3=B 4=C. 기본 4.
    description  추첨·목록 GUI에 보여줄 설명. 한 줄에 하나씩 따옴표로 적습니다.
                 & 색 코드를 쓸 수 있고, 빈 줄("")로 문단을 나눌 수 있습니다.

ability 항목
    class               (필수) 어느 ability class에 속하는지
    name                액션바 쿨타임에 보여줄 이름. 없으면 id를 그대로 씁니다
    trigger             아래 목록 중 하나. 기본 right_click
    item                트리거로 쓸 손에 든 아이템. 없으면 아무거나
    cooldown            초 단위. 기본 0 (쿨타임 없음)
    passive_interval    trigger가 passive일 때 tick 간격. 기본 20
    event               trigger가 passive일 때만. 주기 대신 이 이벤트로 발동

trigger 종류
    right_click     손에 든 아이템으로 우클릭
    left_click      좌클릭
    passive         passive_interval 마다 자동
    on_hit          내가 남을 때렸을 때
    on_damaged      내가 맞았을 때
    on_kill         내가 죽였을 때
    on_death        내가 죽었을 때


이벤트로 발동하는 패시브
------------------------
패시브는 원래 passive_interval 마다 저 혼자 돕니다.
대신 event: 를 적으면 그 이벤트가 일어날 때마다 발동합니다.

    on load:
        ability "reflect":
            class: "menhera"
            trigger: passive
            event: damage
            cooldown: 5

    on ability use "reflect":
        damage event-entity by 2

event: 에는 스크립트에서 on ~~~: 로 쓰는 이벤트 이름을 그대로 적습니다.
damage, death, join, quit, respawn, break, place, consume, sneak toggle 등
Skript가 아는 이름이면 됩니다. 애드온이 추가한 이벤트도 됩니다.

    event: damage
    event: on damage      ← 앞에 on 을 붙여도 됩니다
    event: "damage"       ← 따옴표도 됩니다

이름을 잘못 쓰면 스크립트를 읽을 때 오류가 나면서 비슷한 이름을 알려줍니다.

이벤트 이름만 봅니다. on right click with a stick 처럼 뒤에 붙는 조건은
무시하므로, 그런 조건은 on ability use 안에서 직접 확인하세요.

이벤트 안에서 쓸 수 있는 값
    player          그 이벤트의 주인공 플레이어
    event-entity    상대편. 때린 쪽 / 맞은 쪽 / 죽인 쪽
    ability damage  피해 이벤트일 때 피해량. 바꾸면 원본에 반영됩니다
    cancel event    능력도 취소하고 원본 이벤트도 같이 취소합니다

주의할 점
    - 게임이 진행 중일 때만, 그 클래스를 가진 참가자에게만 발동합니다.
    - 쿨타임 중이거나 disable 한 능력은 발동하지 않습니다.
    - 능력이 자기 이벤트를 다시 부르는 경우는 한 번만 돌고 멈춥니다.
      (예: damage 로 발동해서 상대를 damage 시키는 능력)
    - 채팅처럼 비동기로 도는 이벤트에는 붙일 수 없습니다. 콘솔에 경고가 뜹니다.
    - 리스너는 게임을 시작할 때 답니다. 능력을 고쳤으면
      /ca reload → /sk reload all 후에 게임을 다시 시작하세요.


액션바
------
액션바는 항상 이 순서로 그려집니다. 비어 있는 칸은 구분선까지 통째로 건너뜁니다.

    상태이상  |  능력 부가 정보  |  능력 쿨타임

    §c기절: 48 §7| §e충전 3/5 §7| §b질투: 13

    상태이상       apply status effect 로 건 것. 남은 tick까지 자동으로 표시
    능력 부가 정보  스크립트가 직접 올리는 글. 아래 참고
    능력 쿨타임     지금 도는 쿨타임. ability 블록의 name: 을 이름으로 씁니다

상태이상은 tick, 쿨타임은 초로 보여줍니다. (20 tick = 1초)
쿨타임 초는 올림이라, 남아 있는데 0으로 보이는 일이 없습니다.

셋 다 비면 액션바를 한 번 지우고, 그 뒤로는 아무것도 보내지 않습니다.

가운데 칸(능력 부가 정보)은 id로 나눠 쓰기 때문에 능력 여러 개가 동시에
글을 올려도 서로 덮어쓰지 않고 나란히 붙습니다.

    set ability info "charge" of player to "&e충전 %{ca.charge::%player%}%/5"
    clear ability info "charge" of player
    clear all ability info of player

    빈 문자열을 넣으면 지운 것으로 칩니다.

액션바는 게임이 진행 중일 때만 그려집니다.


상태이상
--------
기절, 출혈, 빙결처럼 여러 능력이 같이 쓰는 효과를 걸 수 있습니다.
남은 시간은 플러그인이 알아서 깎고, 액션바에 자동으로 표시됩니다.

    on ability use "yandere_jealousy":
        apply status effect "stun" to event-entity for 3 seconds

    on ability use "menhera_love":
        if player has status effect "stun":
            send "&c기절해서 능력을 쓸 수 없습니다." to player
            cancel event

액션바 표시 이름은 on load 에서 한 번 정해둡니다. 안 정하면 id가 그대로 나옵니다.

    on load:
        set the name of status effect "stun" to "&c기절"
        set the name of status effect "bleed" to "&4출혈"

    액션바 예시:  §c기절: 48 §7| §4출혈: 100

이미 걸려 있는데 또 걸면
    apply    더 긴 쪽만 남깁니다. 짧게 다시 걸어도 남은 시간이 줄지 않습니다. (기본)
    stack    남은 시간에 더합니다. 여러 번 걸수록 길어집니다.
    refresh  남은 시간과 상관없이 새 값으로 덮어씁니다. 짧게 걸면 줄어듭니다.
    apply ... if not active
             이미 걸려 있으면 아무것도 하지 않습니다.

    apply status effect "stun" to event-entity for 3 seconds
    stack status effect "bleed" on event-entity for 2 seconds
    refresh status effect "frost" on player for 5 seconds
    apply status effect "mark" to player for 10 seconds if not active

시간은 초로도 틱으로도 적을 수 있습니다. 단위는 반드시 붙이세요.
안에서는 tick으로 들고 있고, 액션바와 remaining ticks 도 tick으로 나옵니다.

    apply status effect "stun" to event-entity for 3 seconds
    apply status effect "stun" to event-entity for 60 ticks    ← 위와 같음

여러 명에게 한 번에 걸 수도 있습니다.

    apply status effect "frost" to all players for 5 seconds
    apply status effect "frost" to players with ability class "menhera" for 5 seconds

상태이상 이벤트
    on status effect apply:              모든 상태이상
    on status effect apply "stun":       그 상태이상만
    on status effect expire "stun":      시간이 다 되어 저절로 풀렸을 때

    이벤트 안에서 쓸 수 있는 값
        player                  상태이상을 받는 플레이어
        event-string            상태이상 id
        status effect duration  걸릴 시간(tick). apply 안에서는 바꿀 수도 있습니다

    cancel event 를 하면 상태이상이 걸리지 않습니다. 면역 능력을 이걸로 만듭니다.

        on status effect apply "stun":
            if player has ability class "menhera":
                cancel event

        on status effect apply:
            if player has status effect "resist":
                set status effect duration to status effect duration / 2

주의할 점
    - 남은 시간은 게임이 진행 중일 때만 깎입니다. 게임이 끝나면 전부 지워집니다.
    - remove status effect 로 직접 지운 경우에는 expire 이벤트가 발생하지 않습니다.
      시간이 다 된 것과 누가 걷어낸 것을 구분할 수 있어야 하기 때문입니다.
    - 상태이상 자체는 이름표일 뿐입니다. "기절이면 못 움직인다" 같은 실제 효과는
      스크립트에서 직접 만들어야 합니다.


능력 동작 작성
--------------
    on ability use "능력id":
        # 여기에 동작을 씁니다

이벤트 안에서 쓸 수 있는 값
    player          능력을 쓴 플레이어
    event-entity    대상. on_hit이면 맞은 쪽, on_damaged면 때린 쪽
    event-number    피해량 (on_hit / on_damaged 일 때)
    event-string    발동한 능력 id
    ability damage  피해량. 읽기와 쓰기 모두 됩니다

    cancel event 를 하면 능력이 취소되고 쿨타임도 걸리지 않습니다.


쓸 수 있는 구문
---------------
표현식 — 플레이어 기준
    ability class of %player%            → "yandere"
    ability class name of %player%       → "얀데레"
    ability class tier of %player%       → 2
    tier display of %player%             → "§c§lA" (색이 들어간 등급 표시)
    abilities of %player%                → 그 플레이어가 가진 능력 id 목록
    %player%'s abilities                 → 위와 같음
    cooldown of %player% for ability %string%   → 남은 초 (올림)
    ability damage                       → 피해량 (set 가능)

표현식 — 등록된 정의 기준 (플레이어와 무관)
    name of ability class %string%       → "얀데레"
    tier of ability class %string%       → 2
    tier display of ability class %string%      → "§c§lA"
    abilities of ability class %string%  → 그 클래스에 속한 능력 id 목록
    all ability classes                  → 등록된 모든 클래스 id
    all abilities                        → 등록된 모든 능력 id
    players with ability class %string%  → 그 클래스를 가진 접속 중인 플레이어들
    trigger of ability %string%          → "right_click"
    name of ability %string%             → "질투" (name이 없으면 id)
    event of ability %string%            → "Damage" (event: 를 적은 패시브만)
    item of ability %string%             → "blaze_rod" (없으면 비어 있음)
    max cooldown of ability %string%     → 정의에 적힌 쿨타임 초 (남은 쿨타임 아님)

표현식 — 상태이상
    remaining ticks of status effect %string% for %player%  → 48 (tick)
    status effects of %player%           → 걸려 있는 상태이상 id 목록
    %player%'s status effects            → 위와 같음
    status effect duration               → apply 이벤트 안에서만. set 가능

조건
    %player% has ability class %string%
    %player% doesn't have ability class %string%
    %player% has ability %string%
    %player% doesn't have ability %string%
    %player% has an ability
    %player% has no ability
    %player% is on cooldown for ability %string%
    %player% is not on cooldown for ability %string%
    ability %string% is disabled for %player%
    ability %string% is enabled for %player%
    %player% has status effect %string%
    %player% doesn't have status effect %string%

효과
    set ability class of %player% to %string%
    give %player% ability class %string%
    remove ability from %player%
    set cooldown of %player% for ability %string% to %number%
    reset cooldown of %player% for ability %string%
    reset all cooldowns of %player%
    disable ability %string% for %player%
    enable ability %string% for %player%
    enable all abilities for %player%
    force %player% to use ability %string% [on %entity%]
    trigger ability %string% for %player% [on %entity%]

효과 — 상태이상
    apply status effect %string% to %player% for %number% (seconds|ticks)
    apply status effect %string% to %player% for %number% (seconds|ticks) if not active
    stack status effect %string% on %player% for %number% (seconds|ticks)
    refresh status effect %string% on %player% for %number% (seconds|ticks)
    remove status effect %string% from %player%
    clear all status effects from %player%
    set the name of status effect %string% to %string%

효과 — 액션바 부가 정보
    set ability info %string% (of|for) %player% to %string%
    clear ability info %string% (of|for) %player%
    clear all ability info (of|for) %player%


능력 잠시 끄기
--------------
disable 한 능력은 그 플레이어에게만 발동하지 않습니다.
우클릭이든 passive든 on_hit이든 전부 막힙니다. 정의 자체는 그대로 남습니다.

    on ability use "silence":
        disable ability "yandere_jealousy" for event-entity
        wait 10 seconds
        enable ability "yandere_jealousy" for event-entity

능력을 잃거나 클래스가 바뀌면 꺼둔 목록도 같이 지워집니다.


능력 직접 발동시키기
--------------------
force ... to use 는 on ability use 이벤트를 그냥 발생시킵니다.
쿨타임을 확인하지도 않고 새로 걸지도 않습니다. 필요하면 직접 거세요.

    on ability use "combo":
        force player to use ability "yandere_jealousy" on event-entity
        set cooldown of player for ability "yandere_jealousy" to 10

on 뒤에 넣은 엔티티는 이벤트 안에서 event-entity 로 읽힙니다.


주의
----
ability class 를 먼저 정의하고 그 다음에 ability 를 정의하세요.
같은 on load 블록 안에서 위에서 아래 순서로 실행됩니다.

능력을 스크립트에서 지우고 리로드해도 이미 등록된 정의는 남아 있습니다.
완전히 지우려면 서버를 재시작하세요.
